# 📚 座位预约助手 —— 安卓自动预约APP（完全独立运行！）

> 这不是网页、不是脚本、不是桌面程序。
>
> **这是真真正正的 Android 原生 APK** —— 装到手机上 → 填一次密码 → 设置好权限 → **每天 07:59 和 16:59 自动帮你抢号**，再也不用开电脑。

---

## ✅ 核心功能：真·自动跑

| 模块 | 作用 | 为什么能"自动跑" |
|---|---|---|
| ⏰ **AlarmManager 精确闹钟** | 每天 07:59 / 16:59 到点 **立即唤醒** | 使用 `setExactAndAllowWhileIdle`，**Doze 省电模式下也能触发** |
| 🔁 **自动重复调度** | 执行完当天，**自动调度第二天**同一时间 | 只要手机没关机，每天都会跑 |
| 🔔 **前台常驻通知服务** | 通知栏常驻一条「座位预约保活中」 | Android 认定为"用户需要的前台服务"，**不会被系统杀死** |
| ⚡ **WakeLock 执行锁** | 闹钟响了自动点亮CPU执行，不会抢着一半睡着 | 每次预约任务最多拿 10 分钟锁，足够跑完 30 次重试 |
| 🚀 **BootReceiver 开机自启** | 手机重启后 **自动恢复闹钟 + 前台服务** | 不需要你重新打开APP |
| 🛡 **WorkManager 周期兜底** | 每 15 分钟检查一次：闹钟杀了？重建。服务死了？重启。 | 国产ROM（MIUI/HarmonyOS/ColorOS）杀得狠的时候，这一层把它拉回来 |
| 🎯 **30 次重试 + 智能等待** | 和你原 Python 脚本逻辑完全一致 | 从返回消息里解析"xx:xx:36"秒数 → 等到整秒再继续抢 |

## 🚀 如何获得 APK 安装包（3步）

> Windows 电脑上没有 Android SDK 也没关系，下面用 **GitHub Actions 云端构建**，你只要点几下鼠标。

### ① 创建一个 GitHub 仓库

1. 打开 <https://github.com/new>（登录/注册 GitHub）
2. Repository name 随意，比如 `SeatBooking`
3. 选择 **Public** 或 **Private** 都行（Public 免费额度够用）
4. **不要**勾选任何初始化选项（不建 README、不建 .gitignore）
5. 点最下面 **Create repository**

### ② 上传本项目的文件

把本地目录里 **下列所有文件和文件夹** 上传到仓库根目录（保留层级结构）：

```
你的本地目录
├── .github/workflows/build-apk.yml     ← 云端自动打包脚本
├── app/                                ← APP源码（Kotlin）
│   ├── build.gradle.kts
│   ├── proguard-rules.pro
│   └── src/main/                       ← 全部资源 + 代码
├── gradle/wrapper/gradle-wrapper.properties
├── build.gradle.kts
├── settings.gradle.kts
├── gradle.properties
├── .gitignore
└── （本说明文件）
```

> 简单方法：在新仓库页面中间点 **"…or upload an existing file"** → 把上面的所有拖进去 → 页面底部 **Commit changes**。

### ③ 等构建完成，下载 APK

1. 回到仓库主页，点顶部 **Actions** 标签
2. 会看到一条正在运行的 **Build SeatBooking APK (Android Gradle)** 任务
3. 等它变成 ✅ **绿色**（一般 8~15 分钟），点进去
4. 页面底部 **Artifacts** 区，会有一个 `app-debug.apk` 之类的文件 → 点它下载

把下载好的 APK 传到手机（微信/数据线/云盘都行），点 **安装** 即可。
如果提示"未知来源"或"禁止安装"，请在手机设置里允许该浏览器/文件管理器安装未知应用。

## 📱 首次使用必须做的 5 件事

> 🔥 **以下步骤必须做完，否则定时触发概率会被国产ROM降到接近 0%。**
> 全程约 2 分钟。

### 第 1 步：填账号 + 勾选场次 + 保存

打开APP，填好：
- **学号**（默认预填了 202308090146，对的就不用改）
- **密码**：明文填就行，APP 里自动 Base64 编码后再发送，和原脚本完全一致
- **阅览室号**：默认 26
- **座位号**：默认 2-265
- **☑ 上午场** / **☑ 下午场** 勾选要自动抢的

点 **💾 保存并启动**，下面的 **"自动计划"** 会显示 **"每天07:59抢上午场  每天16:59抢下午场"** 就是成功。

### 第 2 步：弹窗 —— 通知权限 → 允许

Android 13+ 首次启动会请求 **发送通知**。**一定要允许**，否则：
- 保活通知发不了
- "预约成功/失败"的结果提醒你也看不到

### 第 3 步：弹窗 —— 忽略电池优化 → 去设置 → 选「不优化」

这个是重中之重。系统会弹出一个设置页面（中文写"电池优化"）：
1. 顶部下拉框选 **所有应用**
2. 找到 **座位预约助手** → 点进去
3. 选 **不优化**（或者有些ROM叫"无限制"）
4. **完成**

> 如果不小心跳错了，在APP首页点 **🔐 权限配置** 还能再打开这个页面。

### 第 4 步：弹窗 —— 精确闹钟权限（Android 12+）→ 打开开关

同样重要。跳到的页面里找到 **座位预约助手**，把开关打开。
有些ROM 这个页面叫 **闹钟和提醒**。

### 第 5 步（⚠️ 最关键但大家最容易忘的）：手动锁后台

按手机的 **任务键（三条横/方块）** 切到最近任务列表：

| ROM | 操作 | 效果 |
|---|---|---|
| 小米/红米 MIUI | 在任务卡片上 **下拉**，然后点小锁头 🔒 | 显示"已锁定后台"就不会被一键清理 |
| 华为/荣耀 HarmonyOS | **下拉** 任务卡片，点锁头 🔒 | 同上 |
| OPPO/一加 ColorOS | 任务卡片 **长按** → 锁定 | |
| vivo OriginOS | 任务卡片 **长按** → 加入白名单 | |
| 三星 OneUI | 打开「智能管理器」→ 电池 → 内存 → 排除列表 → 添加本APP | |

然后还要：**手机管家 → 应用管理 → 座位预约助手 → 自启动 → 允许！**
（小米叫"自启动"，华为叫"关联启动/后台活动"，OPPO叫"允许完全后台行为"，开关全部打开就行。）

✅ **做完这 5 步，你的手机就能全自动抢号了！**

## 🕐 什么时间抢

和原脚本完全一致：

| 场次 | 预约的时间段 | APP **触发时间** |
|---|---|---|
| 🌅 上午场 | **07:00 ~ 13:50** | 默认 **每天 07:59**（可改） |
| 🌆 下午场 | **13:50 ~ 22:30** | 默认 **每天 16:59**（可改） |

> 为什么是 07:59 / 16:59？因为原脚本就是要在这个时间点"提前排队刷"，
> 等真正一放号，直接第一个命中。你也可以自己改这两个时间（比如 07:59:30 / 16:59:30）。

## 🛠 修改和重建

想改场次时间？改重试次数？改座位号？
直接改 `app/src/main/java/org/gsupl/seatbooking/` 下的文件，然后推送 GitHub，Actions 会自动构建新的 APK。

常见改动点：
- **改重试次数**：`BookingEngine.kt` 里的 `MAX_TRY`（默认30）
- **改 beskid/beskCanId/时间段**：`BookingApi.kt` 里 `book()` 函数
- **改默认触发时间**：`Prefs.kt` 里 `morningTriggerHm` / `afternoonTriggerHm` 的默认值
- **改请求 URL**：同样是 `BookingApi.kt`

## ❓ 常见问题

**Q：日志里一直「HTTP失败」或「网络错误」？**  
A：先确认手机本身能打开 `https://seat.gsupl.edu.cn/`。校园内网/VPN问题的话让手机保持连校园网（或用支持校园网的Wi-Fi）再试。

**Q：到点没任何反应？**  
A：看日志里有没有"⏰ 下一次闹钟：xx:xx"。没有就点 **🔄 重新设置闹钟**，然后确认电池优化、精确闹钟、自启动三个权限都给了、后台锁了。

**Q：Actions 里构建失败？**  
A：点进那条失败的任务 → 拉到最底下 Build step → 看红色报错文字。绝大多数情况是 Gradle 下载某个 maven 依赖时网络波动，在 Actions 页面右上角点 **Re-run jobs** 再跑一次就好。

**Q：我想让它每天 7 点 58 分就开始刷，怎么改？**  
A：APP 首页 → 把"上午场"的时间从 07:59 改成 07:58 → 保存。完事。
